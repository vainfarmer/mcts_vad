Insertion point in `pipeline.py` between the v100 EUBC block and the final dict projection — i.e., AFTER merge, hard NMS, 6b/6c tightening, Stage 7 ensemble, 7b curve correction, MIL-sanity, the category confidence gate, and EUBC. New method `Pipeline._append_recovery_proposals(video_data, anomalies, category)` (~40 lines): for up to K=2 (`recovery_max_extra`) recovery proposals per video: (a) category resolution per the EUBC precedent (detection's own anomaly_type → videomae_category fallback → skip if None/'Normal'/'unknown'/not in anomaly_categories); (b) `rel = frame_scorer.get_category_scores(video_data, cat)` — the already-cached per-video+category relative CLIP curve (read-only, never re-fused; None → skip); (c) boolean mask over timestamps covered by current final detections; (d) SEED: t2 = argmax of rel over UNMASKED indices; FIRE GATE `rel[t2] >= recovery_gate(0.5) * rel.max()` else break; (e) boundaries via the v51 half-max crossing machinery, semantics PINNED by the independent sim reproduction: `hm = (rel[t2] + p20(whole-video rel))/2.0`, walk L/R from t2 while rel >= hm — mask used ONLY for seed selection, walk unblocked (pinned variant +0.0111 vs +0.0063 mask-blocked) — then symmetric duration clamp to `CATEGORY_DURATION_PRIORS[cat]['expected_duration'][1]` about ts[t2] and extension up to `priors['min_segment']`; (f) append `{'t_start','t_end','confidence': recovery_conf(0.01), 'anomaly_type': cat, 'recovery': True}` and add interval to mask before next k. Existing detections, curves, boundaries, confidences, ranks, count, NMS, and every upstream stage NEVER modified; no re-NMS, no re-gating, no VLM/CLIP/MIL/VideoMAE calls. Logging: per-proposal `[Recovery]` fire/skip lines + exactly one `[Recovery] summary:` line per video at ALL return paths. Greedy-safety: `evaluate.compute_temporal_map` pools ALL detections into one globally confidence-sorted list with greedy one-to-one GT matching and an 11-point precision-envelope AP; a dead-last proposal can only match GT no higher-ranked detection claimed — the AP envelope is monotone non-decreasing (empirically exact in sim: AP@0.5/AP@0.7 unchanged to 5 decimals in all 15+ variants). ## Lessons learned (failure modes confirmed/refuted)

- **FM5 confirmed for the FIFTH consecutive loop, at a new link in the chain.** v98/v99/v100 failed at flag-threading and checklist-located gates; v101 moved the gate into runner code (correct per postmortems) and added COMMAND.txt persistence + fresh-output-dir enforcement — and the failure moved to the last unguarded link: the launch command itself omitted the flag. The new persistence mandate is what made this detectable in minutes post-hoc; without it this loop would have been recorded as a clean negative result for BRP. Process rule going forward: the launch command for any flag experiment must be generated from a persisted, flag-verified COMMAND.txt AND a pre-launch assertion (flag present in the command line) must pass before any VLM spend; the pre-live deterministic gate must be a hard precondition, not a skippable step.
- **FM2 (detection-count/rank perturbation) remains refuted by construction and by sim — but was never tested live.** The bottom-rank append monotonicity proof held exactly in every deterministic variant (AP@0.5/AP@0.7 invariant to 5 decimals), corroborating that append-only is the only safe use of the CLIP location signal (vs MIL-v6 -0.023, CPRA -0.0169, Soft-NMS kills). The live AP@0.5/AP@0.7 regressions observed this loop are flag-off VLM noise, not mechanism effects.
- **Sim-vs-live gap reconfirmed:** deterministic sims on cached predictions cannot model the ±0.03 VLM rerun band; smoke reproduced v97 exactly (0.15035 = 0.15035, small sample) while full drifted -0.022 on identical code. Sub-0.01 mechanisms are unevaluable by naive live A/B — only deterministic flag-ON/OFF re-scoring of the same run's JSONs adjudicates, which is precisely the adjudication this proposal pre-registered and the loop never reached.
- **Evidence-audit value confirmed:** C's independent reproduction caught two oracle artifacts (curve-seeding margin ~0 live-faithful; K-dilution not reproducing under pred-cat) before any VLM spend — the corrected +0.006/+0.007 band and the M2 pre-registered kill rule are the right numbers any future BRP retry must be judged against.
