## 1. Mechanism and motivation (closures respected)

DSV = **independent second-model detection-level verification**: the scan VLM (qwen-vl-plus) sees isolated 6s segments and its absolute confidence is uncalibrated (v143 root cause); DSV adds an INDEPENDENT second opinion from a DIFFERENT model (classify client qwen3-vl-plus) on each FINAL detection window, `conf_new = conf_old * (0.6 + 0.4*a)` with the second model's agreement `a∈[0,1]`. Multiplier is bounded in [0.6, 1.0] — it can only attenuate, never amplify, never veto, never move/add/re-rank.

Respected closures:
- **v196 VLC (video-level VLM-read calibration)** VOID'd on M4 the day before — DSV is a different axis (per-DETECTION independent-model evidence, not a per-video level signal), so it does not re-litigate VLC's still-untested level oracle.
- **v183 (CLC) closed the MIL-signal level variant** — DSV uses no MIL signal.
- Not per-video normalization (banned 4: destroys level) and not curve-derived within-video re-rank (banned 1): each detection gets its own factor from independent evidence; intra-video order preserved.
- **CGR/CCR relocation family closed (v164–v169)** — DSV moves no windows (windows-frozen).
- **CNV veto family closed on harm (v171/v172)** — DSV never zeroes confidence and never removes a detection (count-frozen; multiplier floor 0.6, not 0.0).
- v192–v195 train-localization/research no-gos untouched; DSV needs no train labels.
