## Proposal (condensed)

NOCLS-CA-v2 is a flag-gated, FM12-clean **whole-call DROP** of the Stage-7 ensemble-classify VLM
sub-tree (`qwen3-vl-plus`), the second dominant VLM path and the only one never touched in v5.
Inside `_ensemble_classify` (pipeline.py:2765) two shapes issue classify calls:
(a) the VideoMAE-Normal/low-conf else-branch `_classify_clip_guided` (pipeline.py:2768, <=1 call), and
(b) the confusion-pair majority vote (`self.classify_llm_client.generate`, pipeline.py:2962, exactly 3 calls).
The lever inserts ONE architectural test as the first statements of `_ensemble_classify`: if
`config.scoring.classify_skip_class_agnostic` is on, log a per-fire `[NOCLS-CA]` marker and immediately
RETURN the deterministic label already in hand
(`videomae_cat if (videomae_cat and videomae_cat!='Normal') else 'unknown'`) WITHOUT issuing any classify
VLM call. Stage 7 relabels exactly as today (pipeline.py:1207-1208). Detect path
(`anomaly_discovery.scan_segment` / `_directed_llm_scan`) and the VLM-boundary path (pipeline.py:2373)
are untouched; every surviving call is byte-identical.

**mAP-neutral BY CONSTRUCTION:** `compute_temporal_map` (evaluate.py:306-380) builds predictions from ONLY
`{video_id, t_start, t_end, confidence}` and never reads `anomaly_type` — the sole output of the dropped
classify calls. `pred_types` at evaluate.py:474 belongs to `compute_category_accuracy` (a separate Level-4
metric), not mAP. Hence the dropped calls are provably outside the evaluated function's domain.

## C's feedback (gatekeeper) — REJECT, then REVERT-only disposition

C verified both core claims IN CODE:
1. **mAP-neutrality TRUE.** compute_temporal_map (evaluate.py:306-380) uses only {video_id, segment,
   confidence}; anomaly_type never read. Clean DROP-CALL, no FM2/FM3/FM12 risk.
2. **15%-gate UNREACHABLE, provable WITHOUT running.** `_ensemble_classify` runs once/video; per-video
   VLM-call ceiling = confusion-pair 3-vote (pipeline.py:2836-2848) OR `_classify_clip_guided` 0-or-1
   (2905), else 0 ⇒ max 3 calls/video ⇒ ceiling **3/31.969 ≈ 9.4%** of the [COST] per-video mean,
   realistically far less. KEEP gate (b) ≥15% analytically out of reach.

C's verdict: the run yields **no decision-relevant information** — mAP==REF by construction and
call-delta<15% by construction — so it would burn the session's single validating eval (FM11 economy) for
zero new decision info. C also refused to greenlight relaxing the 15% gate / FM12 (hard session
constraints, outside a lever's remit). Disposition: pre-registered KEEP-FLAG-OFF, measurement-only; NOT a
KEEP candidate.

## Keep/Revert decision + reason

**REVERT.** KEEP-rule (b) FAILS: VLM-call reduction = **-7.5% < 15% required**. The wall-clock -48.3% is
qwen API-drift noise (v124-v131 swung 135-275s on near-identical call counts), never decisive. The
accuracy floor **HELD** — full mAP 0.15846972680619295 >= floor 0.15132, consistent with the
by-construction mAP-neutrality claim (anomaly_type is not an input to compute_temporal_map). The observed
-7.5% is within C's analytic ceiling (<=9.4%, realistically less because most videos hit the 0-call or
1-call `_classify_clip_guided` branch rather than the 3-call confusion vote). Ships default-OFF/removed:
4 files restored from `.qoder/backups/v132/`, diff-verified byte-identical; 0 `classify_skip_class_agnostic`
symbols remain; `import pipeline` OK. Baseline stays v124.

## Lessons (FMs confirmed / refuted)

- **FM12 REFUTED as a risk here (clean DROP-CALL confirmed):** pure `return <label>` whole-call drop, no
  merge/batch/repackage/propagation; every surviving detect + VLM-boundary call byte-identical. Verified in
  code by C.
- **Accuracy floor HELD / mAP-neutral by construction CONFIRMED:** full mAP 0.15847 >= floor 0.15132;
  anomaly_type provably outside compute_temporal_map's domain (evaluate.py:306-380), its only boundary-movers
  ECE/EUBC default-OFF. FM2 impossible (Stage-7 relabel-only, count fixed upstream) — CONFIRMED.
- **FM5 activation PASSED:** [NOCLS-CA] fired 13× smoke / 60× full — the lever really ran; the REVERT is on
  MAGNITUDE, not a no-op (contrast v127/v130/v131 zero-or-tiny-fire).
- **FM10 essential:** headline = drift-free -7.5% call delta (decisive), NOT the -48.3% wall-clock (noise).
- **FM11 economy vindicated:** C correctly noted the ceiling (<=9.4%) was provable WITHOUT a run; the full
  eval confirmed -7.5% but added no decision-relevant info beyond "below gate", exactly as pre-registered.
- **Lever 2 (classify-path pruning) now CLOSED analytically + in vivo:** classify is a per-video single
  `_ensemble_classify` issuing <=3 VLM calls ⇒ structurally capped ~6.5-9.4% of the [COST] mean, below the
  15% construction-neutral KEEP gate on this anomaly-only eval set.
- **Escalation / open finding:** under strict FM12 no >=15% construction-neutral lever appears to exist on
  this pipeline+eval — scan-path is max_scan-bound (v125/v130/v131), classify <=~9.4% (v132), whole-video
  early-exit dead on the 100%-anomaly eval (v127). The next KEEP-eligible candidate must be a provably-null
  DROP on the DOMINANT detect/scan path that is NOT merely the max_scan tail and does NOT change detections
  (FM2). Relaxing the 15% gate / FM12 is a policy decision outside a lever's remit (C declined).
- **[COST] concurrency-inflation caveat recorded:** sum-of-per-video-deltas (2072) vs ~696 true calls ⇒
  ~3x overlap inflation; the exact classify [COST] share is only obtainable by measurement, bounded
  [~2%, ~6.5%]; in all cases < 15%.
