## Proposal

**Title:** v127 CNG-DUAL — CLIP+MIL dual-agreement whole-video Normal early-exit gate on the directed VLM scan (cascade rejection with orthogonal-signal safety; training-free, config-gated, default-OFF).

**Mechanism:** Add a near-free, video-level cascade REJECT stage at the top of `pipeline._directed_llm_scan` (pipeline.py:1904), upstream of every per-segment `scan_segment` VLM call. When `config.discovery.clip_normal_gate` is ON, compute two already-cached cheap orthogonal signals once per video: (1) `clip_peak` = max over segments of `AnomalyExpert.batch_score_segments(segments, precomputed)['anomaly_score']` (softmax anomaly/normal ratio in [0,1], pure matmul on cached CLIP features, NO new encode/API call); (2) `mil_max` = `np.max(video_data['mil_scores'])` (the 32-vector MIL snippet score already computed at pipeline.py:997, `.cpu().numpy()`, FM9-safe). The whole directed scan is skipped (`return []`) ONLY IF BOTH cheap detectors agree normal: `clip_peak < clip_normal_gate_floor` (default 0.5, on the PEAK not the mean) AND `mil_max < clip_normal_gate_mil_floor` (default 0.3, the same MIL-normal threshold the pipeline already trusts at line 1224). If `mil_scores is None` (too few frames for 32-snippet MIL) the MIL condition is treated as NOT-normal (`mil_max = +inf`), so the gate is conservatively inert. Returning `[]` routes into the pipeline's existing '0 detections' normal path (pipeline.py:1121-1128), so ZERO scan_segment VLM calls are issued for that video. Viola-Jones/LayerSkip cascade-reject upgraded to a two-signal AGREEMENT gate (FrugalGPT committee routing) to defeat both the v125 no-op failure and the single-CLIP recall hole.

**Rationale (short):** The per-segment directed scan is the dominant VLM sink (~10-18 sequential `scan_segment` calls/video). On UCF-Crime ~50% of test videos are Normal; skipping the whole scan on a genuinely-normal video is mAP-neutral by construction (no GT segment ⇒ emitting 0 detections can only remove FPs, never lose a TP). B's whole-video cascade is the large lever; A's orthogonal MIL rung is the safety that closes B's recall hole (a true anomaly with a weak CLIP peak is NOT gated as long as MIL fires). Categorically different from v125 PREGATE (segment-level mean-relative threshold sat below top-rank selection ⇒ empty intersection) and v126 TRLM (verdict propagation ⇒ FM2 candidate collapse, −0.026 mAP): CNG-DUAL neither operates inside anomalous videos' candidate set nor merges/propagates any verdict.

**Expected gain:** Fleet-average VLM drop ≈ F × ~14 where F is the dual-agreement fire rate; clearing the 15% KEEP gate needs F ≥ ~0.34. mAP designed to hold ≥ 0.15132 floor.

## Decision: REVERT

**Reason:** `max(VLM-call −0.3%, wall-clock −37.5%) < 15%` required. The call-count "win" of −0.29% is indistinguishable from VLM nondeterminism — because **the gate fired 0 skips on both smoke and full** (`skip_directed_scan=1` == 0). The activation marker `[CNG] video=` fired (13 smoke / 59 full) proving the gate ran, but `clip_peak < 0.5 AND mil_max < 0.3` was never jointly satisfied on any video reaching the directed scan. Wall-clock rose +37.5% vs REF, but that is API-drift-dominated (FM10) and not the headline. **Accuracy floor HELD** (full mAP 0.16152 ≥ floor 0.15132, and within live-VLM noise of the 0.17076 reference), exactly as mAP-neutral-by-construction predicts for a zero-fire gate. Neutral accuracy with zero call reduction is not worth the added complexity ⇒ REVERT. ## Lessons — failure modes confirmed/refuted

- **FM5 activation PASSED** (real flag + always-on `[CNG]` marker greppable), but the deterministic fire-count gate (`skip_directed_scan=1`) revealed a **literal 0-fire no-op** — the exact v125-class failure C flagged as residual risk #1 (under-firing), now CONFIRMED as the killer. The dual-AND gate was too conservative: no video that reaches the directed-scan branch (i.e. that already has non-empty `clip_regions` from an earlier stage) simultaneously has `clip_peak < 0.5` AND `mil_max < 0.3`. Truly-normal videos with empty `clip_regions` already bypass the scan before the gate, so the addressable sub-population for the gate is precisely the hard cases where at least one cheap signal is elevated.
- **FM1/FM2 immune CONFIRMED** — curve shape of scanned videos byte-identical; no verdict propagation; floor held. This is the intended contrast with v126 (which propagated verdicts and dropped below floor).
- **FM10 CONFIRMED essential again** — the +37.5% wall-clock rise would have looked catastrophic while the drift-free call count was flat; the call-count headline correctly showed a true no-op rather than a regression.
- **Refuted:** the pre-registered fire-rate hypothesis (F ≥ ~0.34). Realized F = 0. Remedy for a future loop is to raise `clip_normal_gate_floor` (and/or `_mil_floor`) so the gate fires on the addressable population — but this loop is a clean true-negative at zero accuracy cost, and the whole-video-cascade family is NOT refuted, only this threshold setting.
- **Correlated-failure false-gate (risk #2) NOT reached** — cannot be adjudicated because the gate never fired; would only matter once thresholds are loosened enough to skip real videos.
