## 4. NORMAL-VIDEO RECOGNITION DESIGN SCHEMES (design-only; NOT evaluated on mAP)

Anchoring fact: perfectly deleting ALL Normal-video FPs is only **+0.00253 mAP** (banned family 9 for the mAP objective), so none of these is pursued for mAP. They matter for **deployment false-alarm rate and frame/video-level AUC**. Each carries a **sub-floor-only invariant** as its mAP-neutrality proof.

**(a) Supervised sub-floor normalcy gate.** Calibrate a `model_mil_v6` video-score threshold `tau` on TRAIN Normals. For a test video with `mil_score < tau`, suppress ONLY detections whose confidence is below the lowest-ever-matched-TP confidence from the committed run (the "sub-floor band").
- *mAP-neutrality proof:* deleting detections ranked strictly below the last matched TP moves NO point on the pooled PR curve — sub-floor dets contribute 0 recall and their removal cannot change precision at any recall the curve actually reaches. Verdict-independent, pre-calibratable, count-reducing only in the sub-floor band.
- *Discipline:* `tau` MUST be TRAIN-only (no test leakage); the lowest-matched-TP confidence is a committed-run constant read once. Neutrality breaks if `tau` is tuned on test or the sub-floor threshold is set above the last-TP confidence.

**(b) Cheap normalcy VLM re-verify.** Issue ONE binary "is this clip normal?" VLM call ONLY on videos where ALL detections are already sub-floor (rare -> low incremental cost). A confident-normal verdict drops those sub-floor dets.
- *mAP-neutrality proof:* touches only the sub-floor band, adds no detection (FM2-safe). Reduces false alarms on ambiguous Normals.
- *Discipline:* gate the call strictly on the all-sub-floor condition to bound cost; a "normal" verdict must never touch an above-floor detection.

**(c) Measurability (additive reporting, no objective change).** Add frame-level and video-level ROC-AUC to `evaluate.py`, reported ALONGSIDE temporal AP:
- frame-level: build a per-frame normal/anomaly label vector from GT segments and integrate the existing `frame_scores` (pipeline.py:1639, computed BEFORE BUE/CBT -> flag-off-identical, unaffected by boundary operators).
- video-level: max-score-per-video AUC over the Normal-vs-anomaly split.
- Purely additive reporting; makes (a) and (b) measurable without perturbing mAP.

**Common invariant:** (a) and (b) each carry the sub-floor-only invariant as their neutrality proof; (c) is additive reporting. All three are the owner's separate test later — NO code shipped this session. Memo: `iteration_logs/ideas/normal_recognition_schemes_20260802.md`.
