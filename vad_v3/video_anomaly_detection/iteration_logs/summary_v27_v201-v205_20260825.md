## 1. The instrument (PROJECT_DOCUMENTATION 8.3.2)

Every terminal-slot operator (section 5 chain) runs DOWNSTREAM of all VLM calls, on cached
motion-energy and CLIP category curves — i.e. deterministic post-processing. So both A/B arms
are computable inside a single eval:

- **arm-ON** = the run's real output (normal path, untouched)
- **arm-OFF** = replay of the remaining deterministic chain from a `deepcopy` snapshot taken
  before the operator, with the operator's whole config family reset to committed defaults

Same videos, same VLM sampling, same detection count; the arms differ by exactly one function
call. Cross-run VLM noise (0.02503 on hard-88) is eliminated **by construction**, not reduced.

Persisted per-video, index-aligned, same length as `anomalies`:
`ab_arm_off_boundaries` (always) and `ab_arm_off_confidences` (always — so confidence-veto
operators are adjudicable too). Adjudicated with the untouched tool:

```bash
python3.14 iteration_logs/analysis_bootstrap_ab.py --new results/<dir> \
  --paired-json ab_arm_off_boundaries --min-delta 0.008 --min-p 0.9
```

**Rig validation, by construction (not by claim).** The three in-place-mutation hazards
(`_cgr_motion_relocate` / `_bue_boundary_union_extension` / `_cbt_category_boundary_tighten`
all mutate `a["t_start"]`/`a["t_end"]`) were defeated by `deepcopy` per arm, and arm
independence was PROVEN in both directions:

| gate | result |
|---|---|
| 0-fire detection -> arms BYTE-IDENTICAL | PASS (`[c-zero]`, v202 rig self-test) |
| firing detection -> arms DIFFER | PASS (`[c-diff]`: arm-ON `[[40.0,60.0]]` vs arm-OFF `[[46.0,48.0]]`) |
| caller snapshot UNMUTATED by the replay | PASS (`[c-alias]`) |
| arms differ by EXACTLY the one flag | PASS (`[c-cfg]`, `cfg_changed=('event_continuation_extension',)`) |
| FM2 count frozen across arms | PASS (`[c-len]`) |
| confidence-veto mode: veto not fired -> delta EXACTLY 0 | PASS (v205 self-test, `n_conf_changed=0` on 4/4) |
| confidence-veto mode: veto forced -> conf delta real | PASS (v205 force-fire, 6 `[SNH-FIRE]`, `n_conf_changed=2` per video, `n_win_changed=0`) |

The confidence-veto trap was handled explicitly: SNH/CNV change confidence and leave boundaries
untouched, so comparing only `ab_arm_off_boundaries` would give an **exact-zero false null**.
v205 therefore ran in `paired-conf` mode; `n_win_changed=0 / n_conf_changed=2` in the force-fire
smoke is the proof the right quantity was being compared.

**Dual-arm applicability (verified):** compatible = ECE, EUBC, CBT, BUE, qscore, CNV, SNH

## 5. Which layer still has headroom, plainly stated

**Boundary layer: arithmetic headroom, no remaining operator.** Raw ceiling +0.66512, but that
formulation permits moves no operator can make. Every mechanism-scoped boundary ceiling on the
roster falls to +0.049 to +0.098, and at the measured 0.137-0.164 transfer factor the realizable
band is +0.007 to +0.016 — straddling the gate. Section 4.1 now shows all such operators
measured-closed. **The binding constraint here is the SIGNAL, not the operator**: motion energy
and the CLIP category curve place the argmax where they place it, and both BUE (outward) and CBT
(inward) already anchor on it, which is exactly why ECE is 97.7% absorbed and 17/23 EUBC
contractions are re-expanded. A better boundary operator on the same curves is very unlikely to
pay; a better *curve* might, and MCS already refuted the cheapest curve substitution.

**Candidate layer: the largest real headroom, and the least reachable.** The +0.67569 total is
vacuous, but the add-only sub-ceiling at median confidence is **+0.37570 (137 windows)** — an
order of magnitude above every other number in this session. Max-matchable TPs are only
70/156 at IoU 0.3, so **more than half of all GT segments currently have no detection that could
ever match them at any ranking**. That is where the mAP actually is. Realizing any of it requires
*proposing correct windows on videos where the VLM scan currently proposes nothing useful* — i.e.
a localizer.

**Ranking layer: the one bounded, unaddressed, in-reach lever.** Strict bracket
**[+0.126, +0.136]**, achievable single-order realisation +0.12618. Decomposed:
**+0.10506 (93%) is cross-anomaly-video confidence calibration** and only +0.00747 is
Normal-video demotion. **No mechanism in the tree addresses the 93% slice.** Crucially, its
supervision requirement is met by labels that already exist and are auditable: separating
anomaly videos from Normal videos and calibrating *across* videos needs only video-level labels,
which UCF-Crime provides for train. This is the highest expected-value next lever in the project,
and section 4.2 shows three prior attempts at it were voided by an instrument bug that the v27
rig has now fixed.

## 6. What instrument a future session would need

**The binding constraint on the candidate layer is the absence of auditable localized train
supervision — not a missing mechanism.** State this precisely, because it changes what the next
session should build:

1. **For the candidate layer (+0.37570 add-only ceiling): an auditable localized-supervision
